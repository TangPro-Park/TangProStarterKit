# docs/audits/ — 감사 흔적 (Tier 3, 안전·규제 도메인)

> 분기·연간 감사 보고서. 외부 감사 또는 자체 점검 결과의 *원본 보존*.
> 의료·금융·법무 등 *결정의 이유가 감사 대상* 인 도메인 전용.

---

## 언제 도입하나

- 외부 사용자 도입 시점
- 규제 적용 가능성 명확해진 시점
- Phase 3+ 진입 (실서비스)

## 작성 규칙

1. 파일명: `YYYY-Q[1-4]_<주제>.md` 또는 `YYYY-MM-DD_<감사주체>.md`
2. 원본 보존 — 사후 수정 X (수정 필요 시 별도 후속 문서)
3. 시크릿·실명 마스킹
4. 결론 + 액션 아이템 + 액션 마감일

## 표준 섹션

```
# YYYY-Q1 — <감사 주제>
## 1. 감사 범위
## 2. 발견 사항 (Findings)
   - 분류: Critical / High / Medium / Low
## 3. 액션 아이템
   - [ ] (담당·마감 명시)
## 4. 결론
## 5. 다음 감사 시 검토할 항목
```

## 도메인별 권장

- **의료**: 개인정보보호법·의료법·HIPAA 매핑
- **금융**: 자본시장법·전금법·SOX 매핑
- **법무**: 변호사법·비밀유지·이해상충 검토
