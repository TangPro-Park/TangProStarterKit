# 🟣 Dynamic Workflows — 대량 병렬·적대검증

> 스크립트로 수십~수백 에이전트를 **결정적(deterministic)** 으로 오케스트레이션하는 모드. 최신 Opus 급 모델에서 권장.
>
> 언제 쓰나 — **대량 독립 작업 + 결정적 제어흐름 + 엄격한 검증** 이 동시에 필요할 때. 에이전트끼리 자유 대화가 필요하면 Agent Teams 가 맞다. 여기서는 *코드가* 흐름을 통제한다.

---

## 1. 왜 스크립트인가

Agent Teams 의 통신은 유연하지만 *비결정적*이다. 같은 입력에도 흐름이 흔들릴 수 있다. Dynamic Workflows 는 **JS 오케스트레이션 스크립트**가 제어흐름을 쥐므로, 동일 입력 → 동일 단계 → 재현 가능한 결과를 보장한다. 대량 배치·검증 파이프라인에 적합하다.

---

## 2. pipeline vs parallel

| 모드 | 동작 | 배리어 | 용도 |
|---|---|---|---|
| **pipeline** | 단계를 순차 연결, 각 단계는 *완료를 기다리지 않고* 다음으로 흘려보낼 수 있음 | ❌ 없음 | 스트리밍·단계 연쇄 |
| **parallel** | N개 에이전트 동시 실행 후 *전원 완료까지 대기* | ✅ 있음 (barrier) | 대량 독립 작업 fan-out → fan-in |

> 핵심 차이 = **배리어 유무.** parallel 은 모두 끝나야 다음으로 간다(집계·판정에 필수). pipeline 은 흘려보낸다(지연 최소화).

---

## 3. 핵심 빌딩블록

```js
// 개념 골격 (의사 코드)
const a = agent({
  prompt: "...",            // 미션 프롬프트
  model: "opus",            // per-agent 모델 선택
  schema: OutputSchema,     // 구조화 출력 (JSON schema) — 결과를 코드로 다룸
  isolation: true,          // per-agent 격리 (컨텍스트·도구 분리)
});

const results = await parallel(items.map(it => agent({ ... })));  // fan-out → barrier
```

| 옵션 | 의미 |
|---|---|
| `agent()` | 에이전트 1개 정의·실행 단위 |
| `schema()` | **구조화 출력** — 결과를 자유 텍스트가 아닌 검증 가능한 구조로 받음 |
| per-agent `model` | 에이전트마다 모델 선택 (무거운 합성 vs 가벼운 분류) |
| per-agent `isolation` | 컨텍스트·도구 격리로 교차 오염 방지 |

## 4. 적대검증 패턴 (Adversarial Verification)

신뢰가 비싼 결과물(재무 판단·규제 응답·사실 주장)은 *생성자 1명*으로 끝내지 않는다.

```
생성자(1) → 산출물
   → 검증자(N)  : 각자 *반박(refute)* 을 시도 — "이게 틀렸다면 어디서?"
   → 판정 패널  : 검증자 반박을 종합해 채택/기각/보완 판정
```

- **N 검증자가 *반박*을 시도** — "맞다고 확인" 이 아니라 "틀린 곳을 찾아라" 로 프롬프트한다. 동조 편향을 깬다.
- **loop-until-dry** — 검증자가 더 이상 새 반박을 못 낼 때까지(=dry) 생성↔검증을 반복한다. 새 반박이 안 나오면 수렴으로 본다.
- **판정 패널(judge panel)** — 검증 결과를 코드가 집계해 최종 판정. parallel 의 배리어로 *전원 완료 후* 판정한다.

---

## 5. 동시성·총량 캡 (안전판)

| 캡 | 권장값 | 이유 |
|---|---|---|
| 동시성 캡 | ~16 | 동시에 도는 에이전트 상한. API 레이트·자원 보호 |
| 총 캡 | ~1000 | 한 워크플로 전체 에이전트 호출 상한. 폭주·비용 사고 방지 |

> 캡 없는 fan-out 은 *비용·레이트 사고*의 1순위 원인이다. 배치를 펼치기 전에 `동시성 캡`·`총 캡`을 반드시 명시한다. (METHODOLOGY 원리 6 — 병행은 *질서 있게*.)
