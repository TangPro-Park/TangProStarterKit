# docs/compliance/ — 규제 매핑 (Tier 3)

> 법조문·규정 ↔ 코드·SPEC 매핑. 어떤 코드가 어떤 법적 요구를 충족하는지 추적.

---

## 언제 도입하나

- 규제 도메인(의료·금융·법무·개인정보) 진입
- 외부 감사 대비
- 법무팀 검토 결과를 코드에 *영구 박제* 해야 할 때

## 작성 규칙

1. 파일명: `<법령>_<조문>.md` (예: `개보법_제17조.md`)
2. 한 파일 = 한 법령 또는 한 주제 묶음
3. 법조문 원문 발췌 + 해석 + 매핑된 코드·SPEC 링크
4. 변경 이력 — 법령 개정 시 추적

## 표준 섹션

```
# <법령명> <조문>

## 1. 원문 (또는 요약)
> 법조문 원문 또는 공식 요약

## 2. 해석 (자체 또는 법무 자문)

## 3. 매핑된 코드·SPEC
- SPEC_NNN_<주제>
- src/<모듈>/<파일>:<라인>
- 테스트: tests/<...>

## 4. 검증 방법
(이 조항을 우리 시스템이 지키는지 어떻게 증명하는가)

## 5. 변경 이력
- 법령 개정일·우리 대응일 추적
```

## 권장 초기 파일

| 도메인 | 초기 파일 후보 |
|---|---|
| 일반 | `개보법_매핑.md` (대부분 적용) |
| 의료 | `의료법_매핑.md`, `HIPAA_매핑.md` |
| 금융 | `자본시장법_매핑.md`, `전금법_매핑.md` |
| 법무 | `변호사법_매핑.md` |
