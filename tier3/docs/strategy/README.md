# docs/strategy/ — 비즈니스·로드맵 외 전략 문서 (Tier 3)

> 헌법(PROJECT_DIRECTIVE) 보다 가볍고, SPEC 보다 거시적인 *전략 메모*.
> 사업 방향·시장 분석·파트너십·자금·인력 같은 *코드 외부* 문서.

---

## 언제 도입하나

- 외부 자금 / 파트너십 검토 시점
- 시장 진입 전략 정리 필요
- 1년+ 운영 후 회고·재정의

## 작성 규칙

1. 파일명: `YYYY-MM-DD_<주제>.md` (시간순 누적)
2. 분량 자유 — 1쪽~10쪽
3. 시크릿·실명 마스킹 (외부 협업 가능성 고려)
4. 결론은 명확히 — 토론 메모면 "결정 보류" 표시

## 권장 초기 파일

| 파일 | 무엇 |
|---|---|
| `YYYY-MM-DD_시장진입.md` | 타겟 시장 정의·경쟁 환경 |
| `YYYY-MM-DD_파트너십.md` | 외부 협업 검토 |
| `YYYY-MM-DD_자금조달.md` | 부트스트랩 vs 외부 투자 |
| `YYYY-MM-DD_연간회고.md` | 1년 운영 회고·재정의 |

## 표준 섹션 (회고형)

```
# YYYY-MM-DD — <주제>

## 1. 한 줄 요약
## 2. 배경
## 3. 옵션 분석 (있을 시)
## 4. 결정 또는 결정 보류
## 5. 액션 아이템
## 6. 다음 검토 시점
```

## 헌법(PROJECT_DIRECTIVE) 과의 관계

- 전략 문서가 헌법과 충돌하면 → *헌법을 고친다* (전략 문서를 쓰지 X)
- 전략 결정이 헌법으로 승격할 만하면 → 분기 마감 시 헌법 변경 검토
