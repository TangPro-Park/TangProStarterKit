# 스크립트 출력은 본문 paste 필수

Bash · PowerShell · 도구 호출 결과는 *AI 응답 본문에 verbatim paste* 한다.

**Why**: 도구 호출 결과는 *AI 만 보임* — 사용자에게 자동 표시 X. AI 가 결과를 *요약·재가공* 만 하면 사용자는 진짜 출력을 못 봄. 디버깅·확인·결정 모두 *원본 출력* 기반. AI 의 요약은 정보 손실·왜곡 위험.

**How to apply**:
- 도구 호출 후 결과를 *코드블록* (` ``` ... ``` `) 으로 본문에 paste
- 결과가 길면 *핵심 부분 + 줄임표* 로 표시 (`...` 또는 `[<N> more lines]`)
- *그 다음* 에 AI 의 해석·다음 단계 추가
- 결과 *없는* 명령 (성공만 출력) — 그래도 명시 ("성공, no output")
- 에러 출력은 *반드시* 그대로 paste (요약 X)

**예외**:
- 출력이 너무 거대 (예: 수만 줄 로그) — *처음·끝 + 통계* 로 paste
- 사용자가 명시 "조용히 진행해" / "결과만 알려줘" 면 요약 OK
