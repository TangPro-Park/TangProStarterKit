# 작업·세션 모델 매칭

| 작업 종류 | 권장 세션 모델 | 이유 |
|---|---|---|
| **단순 명령 반복 / 커밋 / 문서 정리** | Haiku 4.5 | 가장 저렴 |
| **셸 디버깅 / 진행 모니터링 / 런북 트러블** | Sonnet 4.6 | 충분 |
| **표준 처리 작업 (정돈·추출 등)** | Sonnet 4.6 | 표준 균형 |
| **SPEC 신설 / 도메인 모델 / 본질 설계** | Opus 4.7 | 깊은 사고 필요 |

**Why**: AI 도구별 비용·속도가 모델에 따라 4~10배 차이. *작업과 모델 mismatch* 시 — 단순 작업에 Opus 사용 = 토큰 낭비 / 본질 설계에 Haiku 사용 = 품질 부족.

**How to apply**:
- 사용자 지시 작업의 *복잡도* 1초 평가 → 권장 모델 자기-확인
- 세션 시작 시 *현재 모델* 과 *작업 권장 모델* 비교 — 미스매치면 사용자에게 *전환 제안* (예: "지금 Opus 인데 이 작업은 Sonnet 으로 충분할 듯, 전환?")
- *그러나* 사용자 명시 모델 지시 우선 — 사용자가 "Opus 로 가자" 면 그대로
- 자동 다운/업그레이드 X — 사용자 명시 결정만
