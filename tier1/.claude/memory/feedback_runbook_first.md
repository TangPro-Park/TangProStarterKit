# 런북 먼저

트러블 발생 시 **다음 순서**:

1. `docs/runbook/<관련>.md` 의 트러블슈팅 섹션 *먼저* 확인
2. 매칭 시 — 박제된 해결책 적용 (시도-실패 반복 X)
3. 매칭 없음 — 정상 진단 진행
4. 해결 후 — *런북에 박제* (다음 사람·다음 AI 가 같은 시도 안 하게)

**Why**: 같은 트러블 (예: claude CLI 인증 실패 / Docker bind mount 깨짐 / WSL/host 환경 격리 etc.) 가 *여러 세션 반복* 발생. 매번 검색 + 시도 + 실패 + 정정 → 시간 누적. 첫 발견 시 *런북 박제* 면 다음부터 1분 해결.

**How to apply**:
- 새 트러블 시 — *항상* 런북부터 검색. 직관 진단 X
- 런북에 없으면 — 진단 + 해결 후 *2 곳에 박제*:
  - 코드 주석 (다음에 만지는 사람용)
  - 런북 (처음 만지는 사람용)
- 같은 트러블 2번째 만나면 — *반드시* 런북 박제 (1번째는 발견·박제 동시)
- 박제 형식: 증상·원인·해결·예방. 짧게 쓰기보다 *다음 사람이 검색해서 찾을 수 있는 키워드* 풍부히
