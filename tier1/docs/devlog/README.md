# docs/devlog/ — 일자별 결정 일기

> 작업한 날의 *왜* 와 *트레이드오프* 1차 기록.

---

## 작성 규칙

1. 파일명: `YYYY-MM-DD_<주제슬러그>.md`
2. 작업한 날만 생성 (빈 날 파일 X)
3. 한 날 두 큰 주제 → 두 파일로 분리
4. 시크릿·실명·실 사번 등 민감정보 평문 기록 금지
5. "커밋했음" 만 적지 말 것 — *이유* 적기

## 표준 섹션

→ [`_TEMPLATE.md`](_TEMPLATE.md)

## 무엇을 적나 (정신 모델)

- ✅ 트레이드오프 분석한 결정
- ✅ 막혀서 우회한 사실 + 우회 사유
- ✅ 외부 라이브러리 도입 검토와 결정
- ✅ 결정 보류 (다음에 결정할 것 + 시한)
- ❌ 단순 typo 수정 (commit 메시지로 충분)
- ❌ 잡담·곁가지

## 운영 팁

- 작업 시작할 때 빈 파일 만들고 1줄 적어두기 → 종료할 때 보강
- "오늘 결정 보류한 것" 1줄은 *반드시* — 다음 세션이 빠르게 이어 받음
- 1주에 1번 모아 회고 (Tier 2 의 CHANGELOG 와 연결)
