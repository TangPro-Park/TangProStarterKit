# 명사 어휘집 (Glossary)

> *호칭의 단일 출처*. 새 화면·계층·외부채널 추가 시 *해당 PR에서 본 문서 1줄 갱신* 룰.
>
> - **이 문서**: 명사 (호칭 → 정의 — *뭐가 뭔지*)
> - **[`ORDERS.md`](ORDERS.md)**: 동사 (트리거 → 액션 — *뭘 시키는지*)

룰:
1. 한 항목 = 한 줄 정의 + (필요 시) 헷갈리는 것과의 차이
2. 정의가 분쟁 가능한 것만 박제. 명백한 일반 용어 금지
3. 사용자가 명시 결정한 호칭은 즉시 박제
