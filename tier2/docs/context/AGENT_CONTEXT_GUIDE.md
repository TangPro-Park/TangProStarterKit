## 2. 5분 컨텍스트 회복 경로

```
1. 본 파일 (지금 읽는 중)            → 프로젝트 전체 한 페이지
2. docs/ROADMAP.md                  → "지금 어디?"
3. docs/CHANGELOG.md 최상단 1~2 항목 → "직전에 뭐 했나?"

5. 필요 시 관련 devlog               → "왜 그렇게 결정?"
```
